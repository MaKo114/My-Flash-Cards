# โครงสร้าง frontend

เอกสารนี้อธิบายว่าโค้ดแต่ละส่วนอยู่ไฟล์ไหนและทำหน้าที่อะไร อ่านไล่จากบนลงล่างได้

## ภาพรวม

```
src/
  main.tsx            จุดเริ่มต้น: render <App /> ลงหน้าเว็บ
  App.tsx             ประกอบทุกส่วนเข้าด้วยกัน และเก็บ state ที่หลายหน้าใช้ร่วมกัน
  index.css           Tailwind และระบบสี (โหมดสว่าง/มืด)
  views/              หน้าหลัก 4 หน้า หนึ่งไฟล์ต่อหนึ่งหน้า
  components/         ชิ้นส่วน UI ที่ใช้ประกอบหน้า
  hooks/              state และการดึงข้อมูล แยกออกจาก UI
  lib/                ฟังก์ชันล้วนและการเชื่อมต่อภายนอก (API, localStorage, เสียง)
```

ข้อมูลไหลทางเดียว: **hooks** โหลดและเก็บข้อมูล → **App** ส่งข้อมูลผ่าน props ลงไปที่ **views** → views ส่งต่อให้ **components** เมื่อผู้ใช้กดอะไร component จะเรียกฟังก์ชันที่ได้รับมาทาง props (เช่น `onEdit`) ส่งกลับขึ้นไป

## lib/ (ฟังก์ชันล้วน ทดสอบง่าย)

| ไฟล์ | หน้าที่ |
| --- | --- |
| `cards.ts` | ชนิดข้อมูล `Card` และฟังก์ชันคำนวณทั้งหมด เช่น กรอง ค้นหา สุ่ม ตัวเลือกข้อสอบ ตารางทบทวน แผนฝึกวันนี้ ส่งออก CSV มี unit test ใน `cards.test.ts` |
| `settings.ts` | ค่าตั้งของอุปกรณ์ และการอ่าน/เขียน localStorage แบบตรวจค่าทีละช่อง |
| `api.ts` | เรียก backend ทุกเส้น แนบ token และแจ้งเมื่อเจอ 401 |
| `card-cache.ts` | เก็บรายการคำล่าสุดในเบราว์เซอร์เพื่อเปิดเว็บได้ทันที |
| `speech.ts` | อ่านออกเสียงคำอังกฤษตามความเร็วและสำเนียงที่ตั้งไว้ |
| `answer-sound.ts`, `random.ts`, `utils.ts` | เสียงตอบรับ ตัวสุ่มที่กำหนด seed ได้ และ `cn()` สำหรับรวม class |

## hooks/ (state และการดึงข้อมูล)

| hook | หน้าที่ |
| --- | --- |
| `useSession` | ตรวจว่าต้องใช้รหัสผ่านไหม เข้าสู่ระบบ ออกจากระบบ |
| `useSettings` | โหลด/บันทึกค่าตั้ง และใช้ธีมกับเสียงอ่านตามค่านั้น |
| `useCardLibrary` | ทุกอย่างเกี่ยวกับรายการคำ: โหลด บันทึก ดาว คำตอบ Challenge ลบพร้อมเลิกทำ นำเข้า/ส่งออก และประวัติการฝึก |
| `useChallengeRound` | สถานะของรอบ Challenge หนึ่งรอบ: คำชุดไหน อยู่คำที่เท่าไร จำได้/จำไม่ได้กี่คำ |

เทคนิคที่ทำให้เว็บรู้สึกเร็วอยู่ใน `useCardLibrary`:

- **แสดงก่อน บันทึกทีหลัง (optimistic update)** กดดาวหรือตอบ Challenge แล้วหน้าจอเปลี่ยนทันที ค่อยส่งไปบันทึก ถ้าไม่สำเร็จจะย้อนค่าคืนหรือแจ้งเตือน
- **คิวต่อคำ** คำตอบของคำเดียวกันถูกส่งตามลำดับ เพราะเซิร์ฟเวอร์คำนวณตารางทบทวนต่อจากคำตอบก่อนหน้า
- **แคช** รายการคำจากครั้งก่อนแสดงทันทีระหว่างรอข้อมูลใหม่

## views/ (หน้าหลัก)

| ไฟล์ | หน้า |
| --- | --- |
| `LibraryView.tsx` | คลังคำศัพท์: ค้นหา กรอง เลือก ลบ นำเข้า/ส่งออก |
| `StudyView.tsx` | อ่านบัตรคำ: พลิกบัตรทีละใบ ปุ่มลัด ← → Space |
| `ChallengeView.tsx` | Challenge: แท็บโหมด หน้าเริ่ม คำถามทีละข้อ และหน้าสรุป |
| `StatsView.tsx` | สถิติการฝึก กราฟ 14 วัน ระดับความจำ คำที่ผิดบ่อย |

## components/

- `layout/` แถบซ้าย (`Sidebar`), หัวเว็บและแท็บบนมือถือ (`MobileHeader`), รายชื่อหน้า (`navigation.ts`)
- `challenge/` คำถามหนึ่งข้อ (`ChallengePanel`) และหน้าเริ่ม/สรุปรอบ (`RoundScreens`)
- `study/StudyCard.tsx` บัตรที่พลิกได้
- `library/CardRow.tsx` แถวคำหนึ่งแถว ใช้ `SwipeRow` ให้ปัดบนมือถือ
- ชิ้นส่วนที่ใช้ร่วมกัน เช่น `CardEditor`, `SettingsDialog`, `TodayPanel`, `PracticeToolbar`, `ConfirmDialog`, `UndoToast`
- `ui/` ปุ่ม ช่องกรอก dropdown และ dialog พื้นฐาน (แบบ shadcn)

`SwipeRow` เป็นตัวอย่างการทำ animation ให้ลื่น: ระหว่างลากจะเขียน `transform` ลง element โดยตรงใน `requestAnimationFrame` แทนการ setState ทุกครั้งที่นิ้วขยับ React จึงไม่ต้อง render ใหม่ระหว่างลาก

## ระบบสีและโหมดมืด

`index.css` ประกาศสีกลางไว้ 4 ตัว ได้แก่ `canvas` (พื้นหลังหน้า), `surface` (การ์ด/กล่อง), `accent` (ปุ่มหลัก) และ `accent-strong` (ตอน hover) ใช้เป็น class เช่น `bg-surface`, `bg-accent`

เมื่อ `<html>` มี class `dark` ระบบจะสลับค่าสีเหล่านี้ และกลับด้านเฉด slate (เช่น `text-slate-900` ยังเป็นตัวอักษรที่เข้มที่สุดเมื่อเทียบกับพื้นหลัง) component ส่วนใหญ่จึงไม่ต้องเขียน `dark:` เอง

## อยากแก้หรือเพิ่มอะไร เริ่มที่ไหน

- เปลี่ยนข้อความหรือหน้าตาของหน้าใด → ไฟล์ใน `views/` หรือ component ที่หน้านั้น import
- เปลี่ยนวิธีคำนวณ (เช่น ระยะทบทวน) → `lib/cards.ts` แล้วเพิ่ม test ใน `cards.test.ts` (backend ใช้ค่าเดียวกันใน `backend/internal/domain/card.go`)
- เพิ่มค่าตั้งใหม่ → `lib/settings.ts` (ค่าเริ่มต้นและค่าที่อนุญาต) แล้วเพิ่มช่องใน `SettingsDialog`
- เพิ่ม API → `lib/api.ts` แล้วเรียกจาก hook ที่เกี่ยวข้อง
