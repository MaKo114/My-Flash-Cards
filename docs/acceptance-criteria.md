# Acceptance Criteria

เกณฑ์ต่อไปนี้อธิบายพฤติกรรมที่ระบบมีอยู่ในปัจจุบัน โดยอ้างอิงรหัสจาก [User Stories](user-stories.md)

## US-01 จัดการคำศัพท์

- เมื่อเพิ่มคำใหม่ ต้องมีคำศัพท์ ชนิดของคำอย่างน้อยหนึ่งค่า และความหมายอย่างน้อยหนึ่งค่า; คำใบ้เว้นว่างได้
- ระบบตัดช่องว่างหัวท้าย ยกตัวแรกของคำศัพท์เป็นตัวใหญ่ และไม่เก็บชนิดหรือความหมายที่ซ้ำกันโดยไม่สนตัวพิมพ์
- คำสะกดเดียวกันโดยไม่สนตัวพิมพ์เพิ่มเป็นบัตรใหม่ไม่ได้ แม้ชนิดของคำต่างกัน; API ตอบ `409` และผู้ใช้แก้บัตรเดิมเพื่อเพิ่มข้อมูลได้
- บัตรหนึ่งใบแสดงชนิดของคำและความหมายทุกค่าที่บันทึกไว้ โดยไม่สรุปว่าค่าในตำแหน่งเดียวกันจับคู่กัน
- แก้ไขบัตรแล้วโหลดหน้าใหม่ยังเห็นค่าที่แก้; ลบบัตรหลังยืนยันในกล่องยืนยันของเว็บแล้วคำสะกดนั้นหายจากคลัง กดยกเลิกแล้วบัตรยังอยู่

## US-02 นำเข้า CSV

- รับไฟล์ UTF-8 ขนาดไม่เกิน 5 MiB และหัวคอลัมน์ตามลำดับ `คำศัพท์,ชนิดของคำ,ความหมาย`; รองรับ BOM ของ UTF-8
- รองรับหลายค่าในหนึ่งช่องโดยคั่นด้วย comma และครอบช่อง CSV ด้วยเครื่องหมาย `"` เช่น `about,"verb, preposition","ประมาณ, รอบๆ, เกี่ยวกับ"`
- ยอมรับช่องว่างก่อนเครื่องหมาย `"` และความหมายที่คั่นด้วย comma โดยไม่ครอบ `"` เช่น `abandon, verb, ละทิ้ง, ทอดทิ้ง`; หากชนิดของคำมีหลายค่าต้องครอบช่องนั้นด้วย `"`
- แถวของคำสะกดเดียวกันรวมชนิดของคำและความหมายที่ยังไม่มีเข้าบัตรเดียว โดยไม่เปลี่ยนคำใบ้หรือสถานะทบทวนเดิม; แถวที่ไม่เพิ่มข้อมูลใหม่ถูกข้าม
- นำเข้าทั้งไฟล์เป็นรายการเดียว หากฐานข้อมูลบันทึกไม่สำเร็จต้องไม่มีแถวใดของรอบนั้นถูกเพิ่ม; อัปโหลดไฟล์เดิมซ้ำแล้วข้ามข้อมูลที่มีอยู่ได้
- ระหว่างนำเข้า แสดงเปอร์เซ็นต์การส่งไฟล์ที่วัดได้จริง สถานะตรวจและบันทึก และสถานะโหลดรายการล่าสุด; ปิดปุ่มนำเข้าซ้ำจนเสร็จ
- ข้ามแถวว่าง รายงานจำนวน `added`, `merged`, `skipped`, `invalid` และเปิดดูเลขแถว คำศัพท์ และเหตุผลของแถวผิดรูปแบบ ข้อมูลไม่ครบ หรือข้อมูลซ้ำได้
- ไฟล์ที่หัวคอลัมน์หรือ encoding ไม่ถูกต้องถูกปฏิเสธก่อนนำเข้า

## US-03 ค้นหา กรอง และลบหลายคำ

- ค้นหาคำสะกดหรือความหมายได้โดยไม่สนตัวพิมพ์และช่องว่างหัวท้าย แต่การค้นหาไม่ใช้ชนิดของคำ
- กรองตามอักษรแรก A–Z ชนิดของคำที่บัตรมี หรือสถานะต้องทบทวนได้; ตัวกรองทำงานร่วมกัน
- รายการแสดงครั้งละ 50 คำ พร้อมจำนวนที่แสดงจากทั้งหมด และกด `แสดงเพิ่ม` เพื่อโหลดอีก 50 คำ; เปลี่ยนตัวกรองหรือคำค้นแล้วกลับไปแสดง 50 คำแรก
- เลือกทั้งหมดที่แสดงหรือเลือกบางคำ แล้วลบรายการที่เลือกหลังยืนยันได้

## US-04 อ่านบัตร

- หนึ่งคำสะกดปรากฏหนึ่งครั้งในรอบอ่าน; การสุ่มไม่ทำให้คำซ้ำในรอบ
- เลือกด้านหน้าเป็นอังกฤษหรือไทยได้ พลิกบัตรเพื่อดูอีกด้าน และไปบัตรก่อนหน้าหรือถัดไปได้ ทั้งด้วยปุ่มและปุ่มลัด `←` `→` (เปลี่ยนบัตร) และ `Space` (พลิกบัตร) เมื่อไม่ได้พิมพ์อยู่ในช่องกรอก
- คำใบ้ที่มีอยู่เปิดดูก่อนพลิกเฉลยได้ และกดออกเสียงคำอังกฤษได้ทั้งสองด้านของบัตรเมื่อเบราว์เซอร์รองรับ `speechSynthesis`
- กดเก็บหรือยกเลิกคำที่ต้องทบทวนแล้วสถานะถูกบันทึก และตัวกรองคำที่ต้องทบทวนสะท้อนค่าล่าสุด

## US-05 Challenge ฝึกพิมพ์

- ก่อนกดเริ่มยังไม่แสดงคำถาม แถบความคืบหน้า และไม่เล่นเสียงของคำศัพท์
- ถ้าตอบไปแล้วอย่างน้อยหนึ่งคำ การเปลี่ยนรูปแบบ ตัวกรอง การสุ่ม หรือออกจากหน้า Challenge ต้องถามยืนยันก่อนเริ่มรอบใหม่; กดยกเลิกแล้วรอบเดิมยังอยู่
- โหมดพิมพ์ตามคำแสดงคำอังกฤษ; โหมดฟังแล้วพิมพ์เล่นเสียงหลังเริ่มเมื่อเบราว์เซอร์รองรับ และมีปุ่มฟังอีกครั้ง
- ขณะพิมพ์ การ์ดแสดงอักษรที่ตรงเป็นสีเขียวและอักษรที่ผิดเป็นสีแดง; เทียบคำสะกดโดยไม่สนตัวพิมพ์
- ช่องพิมพ์คำตอบปิดการเติมคำ แก้สะกด และเปลี่ยนตัวพิมพ์ใหญ่อัตโนมัติของเบราว์เซอร์ เพื่อให้ผู้ใช้ฝึกสะกดด้วยตนเอง
- กด Enter เพื่อส่งคำตอบและไปคำถัดไป; คำสะกดที่มีหลายชนิดของคำถูกถามเพียงครั้งเดียวต่อรอบ
- คำตอบผิดหรือกดดูเฉลยก่อนส่งทำให้คำถูกเก็บไว้ทบทวน; คำตอบถูกยกเลิกสถานะต้องทบทวน และมีเสียงตอบรับเมื่อเปิดใช้งาน

## US-06 Challenge ทบทวนความหมาย

- เลือกให้เห็นอังกฤษหรือไทยก่อน แล้วพิมพ์คำตอบ ดูเฉลย และประเมินตนเองว่า `จำได้` หรือ `ยังจำไม่ได้` โดยกด Enter หลังดูเฉลยเท่ากับ `จำได้`
- เมื่อคำหนึ่งมีหลายความหมาย เฉลยแสดงความหมายทั้งหมดโดยไม่เดาว่าความหมายใดคู่กับชนิดของคำใด
- การประเมินตนเองปรับสถานะต้องทบทวน และสรุปจำนวนที่จำได้หรือยังจำไม่ได้เมื่อจบรอบ

## US-07 ย้ายข้อมูลเดิม

- เมื่อ backend เริ่มทำงาน migration รวมบัตรที่มีคำสะกดเดียวกันโดยไม่สนตัวพิมพ์เป็นหนึ่งบัตร และเก็บชนิดของคำกับความหมายเดิมไว้
- หากบัตรเดิมมีคำใบ้หลายค่า ให้เก็บข้อความคำใบ้ไว้; หากบัตรใดของคำนั้นต้องทบทวน บัตรที่รวมแล้วต้องทบทวนด้วย
- การเริ่ม backend ซ้ำไม่สร้างคำที่ลบไปแล้วกลับมา และไม่สร้างบัตรซ้ำ

## US-08 โหลดคำศัพท์เมื่อเปิดเว็บ

- ถ้าเบราว์เซอร์เคยโหลดคำศัพท์สำเร็จ แสดงรายการนั้นได้ทันทีระหว่างรอ API และเปลี่ยนเป็นข้อมูลล่าสุดเมื่อ API ตอบ
- ถ้า API ล้มเหลว ข้อมูลที่เคยโหลดไว้ยังอ่านได้พร้อมข้อความผิดพลาด; ถ้าไม่มีข้อมูลที่เคยโหลด ให้แสดงสถานะกำลังโหลดจนกว่าคำขอจะจบ

## หลักฐานทดสอบ

- Go unit และ migration integration: `go test ./...` ใน `backend/` โดยกำหนด `MIGRATION_TEST_DATABASE_URL` ให้ชี้ฐานทดสอบสำหรับ integration test
- Frontend unit: `npm test` ใน `frontend/`
- E2E: `npm run test:e2e` ใน `frontend/` โดยใช้ PostgreSQL ทดสอบที่พอร์ต 5433
- CI รันชุดทดสอบเหล่านี้พร้อม `npm run build` ตาม [.github/workflows/ci.yaml](../.github/workflows/ci.yaml)
