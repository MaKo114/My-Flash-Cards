# Acceptance Criteria

เกณฑ์ต่อไปนี้อธิบายพฤติกรรมที่ระบบมีอยู่ในปัจจุบัน โดยอ้างอิงรหัสจาก [User Stories](user-stories.md)

## US-01 จัดการคำศัพท์

- เมื่อเพิ่มคำใหม่ ต้องมีคำศัพท์ ชนิดของคำอย่างน้อยหนึ่งค่า และความหมายอย่างน้อยหนึ่งค่า; คำใบ้และตัวอย่างประโยคเว้นว่างได้
- ถ้ากรอกไม่ครบ ฟอร์มแสดงข้อความภาษาไทยใต้ช่องที่ผิดและย้ายเคอร์เซอร์ไปช่องแรกที่ต้องแก้ โดยไม่ใช้ข้อความเตือนของเบราว์เซอร์
- เมื่อคลังยังว่าง แสดงเฉพาะปุ่มเพิ่มคำแรกและนำเข้า CSV โดยซ่อนสถิติและตัวกรอง; เมื่อตัวกรองไม่พบคำ มีปุ่มล้างตัวกรองทั้งหมด
- ระบบตัดช่องว่างหัวท้าย ยกตัวแรกของคำศัพท์เป็นตัวใหญ่ และไม่เก็บชนิดหรือความหมายที่ซ้ำกันโดยไม่สนตัวพิมพ์
- คำสะกดเดียวกันโดยไม่สนตัวพิมพ์เพิ่มเป็นบัตรใหม่ไม่ได้ แม้ชนิดของคำต่างกัน; API ตอบ `409` และผู้ใช้แก้บัตรเดิมเพื่อเพิ่มข้อมูลได้
- บัตรหนึ่งใบแสดงชนิดของคำและความหมายทุกค่าที่บันทึกไว้ โดยไม่สรุปว่าค่าในตำแหน่งเดียวกันจับคู่กัน
- แก้ไขบัตรแล้วโหลดหน้าใหม่ยังเห็นค่าที่แก้
- กดลบบัตรแล้วบัตรหายทันทีพร้อมแถบ `เลิกทำ` ประมาณ 6 วินาที; กดเลิกทำแล้วบัตรกลับมาโดยไม่ถูกลบจากเซิร์ฟเวอร์ ถ้าไม่กด บัตรถูกลบจริงเมื่อหมดเวลา เมื่อลบคำอื่นต่อ หรือเมื่อปิดหน้า; ถ้าลบไม่สำเร็จ บัตรกลับมาพร้อมข้อความผิดพลาด
- บนจอแคบกว่า 768px ปุ่มแก้ไขและลบซ่อนอยู่ ปัดแถวไปทางซ้ายเพื่อเปิด และปัดกลับหรือแตะแถวเพื่อปิด; ปัดเร็ว ๆ ตัดสินจากทิศทางทันที ส่วนการลากช้าเปิดเมื่อเกินครึ่ง แถวขยับตามนิ้วโดยไม่กระตุกและหน่วงเมื่อลากเกินขอบ; ปุ่มดาวยังแสดงอยู่เสมอ ส่วนจอกว้างแสดงทั้งสามปุ่มในแถว
- แก้ไขคำจากหน้าอ่านบัตรและระหว่าง Challenge ได้ด้วยปุ่ม `แก้ไขคำนี้` โดยไม่ออกจากหน้านั้น

## US-02 นำเข้า CSV

- รับไฟล์ UTF-8 ขนาดไม่เกิน 5 MiB และหัวคอลัมน์ตามลำดับ `คำศัพท์,ชนิดของคำ,ความหมาย`; รองรับ BOM ของ UTF-8
- รองรับหลายค่าในหนึ่งช่องโดยคั่นด้วย comma และครอบช่อง CSV ด้วยเครื่องหมาย `"` เช่น `about,"verb, preposition","ประมาณ, รอบๆ, เกี่ยวกับ"`
- ยอมรับช่องว่างก่อนเครื่องหมาย `"` และความหมายที่คั่นด้วย comma โดยไม่ครอบ `"` เช่น `abandon, verb, ละทิ้ง, ทอดทิ้ง`; หากชนิดของคำมีหลายค่าต้องครอบช่องนั้นด้วย `"`
- แถวของคำสะกดเดียวกันรวมชนิดของคำและความหมายที่ยังไม่มีเข้าบัตรเดียว โดยไม่เปลี่ยนคำใบ้หรือสถานะทบทวนเดิม; แถวที่ไม่เพิ่มข้อมูลใหม่ถูกข้าม
- รับไฟล์แบบเต็ม 5 คอลัมน์ `คำศัพท์,ชนิดของคำ,ความหมาย,คำใบ้,ตัวอย่างประโยค` ซึ่งแต่ละแถวต้องมี 5 ช่อง; คำใบ้และตัวอย่างประโยคใช้กับคำใหม่เท่านั้น
- ปุ่ม `ส่งออก CSV` ดาวน์โหลดทุกคำในรูปแบบ 5 คอลัมน์ที่ครอบทุกช่องด้วย `"` และนำเข้ากลับได้โดยไม่สร้างข้อมูลซ้ำ
- นำเข้าทั้งไฟล์เป็นรายการเดียว หากฐานข้อมูลบันทึกไม่สำเร็จต้องไม่มีแถวใดของรอบนั้นถูกเพิ่ม; อัปโหลดไฟล์เดิมซ้ำแล้วข้ามข้อมูลที่มีอยู่ได้
- ระหว่างนำเข้า แสดงเปอร์เซ็นต์การส่งไฟล์ที่วัดได้จริง สถานะตรวจและบันทึก และสถานะโหลดรายการล่าสุด; ปิดปุ่มนำเข้าซ้ำจนเสร็จ
- ข้ามแถวว่าง รายงานจำนวน `added`, `merged`, `skipped`, `invalid` และเปิดดูเลขแถว คำศัพท์ และเหตุผลของแถวผิดรูปแบบ ข้อมูลไม่ครบ หรือข้อมูลซ้ำได้
- ไฟล์ที่หัวคอลัมน์หรือ encoding ไม่ถูกต้องถูกปฏิเสธก่อนนำเข้า

## US-03 ค้นหา กรอง และลบหลายคำ

- ค้นหาคำสะกดหรือความหมายได้โดยไม่สนตัวพิมพ์และช่องว่างหัวท้าย แต่การค้นหาไม่ใช้ชนิดของคำ
- กรองตามอักษรแรก A–Z ชนิดของคำที่บัตรมี สถานะต้องทบทวน หรือคำที่ถึงกำหนดทบทวนได้; ตัวกรองทำงานร่วมกัน
- รายการแสดงครั้งละ 50 คำ พร้อมจำนวนที่แสดงจากทั้งหมด และกด `แสดงเพิ่ม` เพื่อโหลดอีก 50 คำ; เปลี่ยนตัวกรองหรือคำค้นแล้วกลับไปแสดง 50 คำแรก
- เลือกทั้งหมดที่แสดงหรือเลือกบางคำ แล้วลบรายการที่เลือกหลังยืนยันได้ และกดเลิกทำได้เหมือนการลบคำเดียว

## US-04 อ่านบัตร

- หนึ่งคำสะกดปรากฏหนึ่งครั้งในรอบอ่าน; การสุ่มไม่ทำให้คำซ้ำในรอบ
- เลือกด้านหน้าเป็นอังกฤษหรือไทยได้ พลิกบัตรเพื่อดูอีกด้าน และไปบัตรก่อนหน้าหรือถัดไปได้ ทั้งด้วยปุ่มและปุ่มลัด `←` `→` (เปลี่ยนบัตร) และ `Space` (พลิกบัตร) เมื่อไม่ได้พิมพ์อยู่ในช่องกรอก
- คำหรือความหมายที่ยาวถูกย่อขนาดตัวอักษรให้อยู่ในบัตรโดยไม่ทับป้ายด้านบนและล่าง และเลื่อนอ่านในบัตรได้เมื่อยังยาวเกิน
- ด้านหลังบัตรแสดงตัวอย่างประโยคเมื่อมี
- คำใบ้ที่มีอยู่เปิดดูก่อนพลิกเฉลยได้ และกดออกเสียงคำอังกฤษได้ทั้งสองด้านของบัตรเมื่อเบราว์เซอร์รองรับ `speechSynthesis`
- กดเก็บหรือยกเลิกคำที่ต้องทบทวนแล้วสถานะถูกบันทึก และตัวกรองคำที่ต้องทบทวนสะท้อนค่าล่าสุด

## US-05 Challenge ฝึกพิมพ์

- ก่อนกดเริ่มยังไม่แสดงคำถาม แถบความคืบหน้า และไม่เล่นเสียงของคำศัพท์
- ถ้าตอบไปแล้วอย่างน้อยหนึ่งคำ การเปลี่ยนรูปแบบ ตัวกรอง การสุ่ม หรือออกจากหน้า Challenge ต้องถามยืนยันก่อนเริ่มรอบใหม่; กดยกเลิกแล้วรอบเดิมยังอยู่
- โหมดพิมพ์ตามคำแสดงคำอังกฤษ; โหมดฟังแล้วพิมพ์เล่นเสียงหลังเริ่มเมื่อเบราว์เซอร์รองรับ และมีปุ่มฟังอีกครั้ง
- ขณะพิมพ์ การ์ดแสดงอักษรที่ตรงเป็นสีเขียวและอักษรที่ผิดเป็นสีแดง; เทียบคำสะกดโดยไม่สนตัวพิมพ์
- ช่องพิมพ์คำตอบปิดการเติมคำ แก้สะกด และเปลี่ยนตัวพิมพ์ใหญ่อัตโนมัติของเบราว์เซอร์ เพื่อให้ผู้ใช้ฝึกสะกดด้วยตนเอง
- กด Enter เพื่อส่งคำตอบและไปคำถัดไป; คำสะกดที่มีหลายชนิดของคำถูกถามเพียงครั้งเดียวต่อรอบ
- คำตอบผิดหรือกดดูเฉลยก่อนส่งทำให้คำถูกเก็บไว้ทบทวน; คำตอบถูกยกเลิกสถานะต้องทบทวน และมีเสียงตอบรับเมื่อเปิดใช้งาน
- หลังตอบถูก คำถัดไปแสดงภายในประมาณ 0.3 วินาที (โหมดเลือกคำตอบ 0.45 วินาที) โดยไม่รอเซิร์ฟเวอร์ ผลถูกบันทึกเบื้องหลัง ลองใหม่เองสูงสุด 3 ครั้ง และแจ้งข้อความเมื่อบันทึกไม่สำเร็จ
- เปลี่ยนรูปแบบ Challenge แล้วเริ่มรอบเดิมใหม่ด้วยคำชุดเดิม ส่วนการเปลี่ยนตัวกรองหรือจำนวนคำต่อรอบสร้างชุดคำใหม่
- เลือกจำนวนคำต่อรอบได้ 10, 20 (ค่าเริ่มต้น), 50 หรือทุกคำ; รอบที่จำกัดจำนวนแสดงช่วงคำ เช่น `คำที่ 1–10 จาก 12 คำ` และเมื่อจบรอบกด `ชุดถัดไป` เพื่อฝึกคำช่วงถัดไปตามลำดับเดิม ส่วน `เริ่มรอบใหม่` กลับไปช่วงแรกและสุ่มลำดับใหม่เมื่อเปิดสุ่มคำ
- เมื่อจบรอบ แสดงรายการคำที่ยังจำไม่ได้พร้อมความหมาย และกด `ฝึกเฉพาะคำที่ผิดอีกรอบ` เพื่อเริ่มรอบที่มีเฉพาะคำเหล่านั้นทันที
- ทุกรูปแบบของ Challenge ใช้จำนวนคำต่อรอบ รายการคำที่ยังจำไม่ได้ และการฝึกคำที่ผิดอีกรอบเหมือนกัน
- บนจอแคบกว่า 640px เมื่อเริ่มรอบแล้ว รูปแบบและตัวกรองถูกพับเป็นแถบเดียวพร้อมปุ่ม `ตั้งค่า` เพื่อให้คำถามอยู่ในจอ

## US-06 Challenge ทบทวนความหมาย

- เลือกให้เห็นอังกฤษหรือไทยก่อน แล้วพิมพ์คำตอบ ดูเฉลย และประเมินตนเองว่า `จำได้` หรือ `ยังจำไม่ได้` โดยกด Enter หลังดูเฉลยเท่ากับ `จำได้`
- เมื่อคำหนึ่งมีหลายความหมาย เฉลยแสดงความหมายทั้งหมดโดยไม่เดาว่าความหมายใดคู่กับชนิดของคำใด
- เฉลยแสดงตัวอย่างประโยคเมื่อมี; โหมดเลือกคำตอบแสดงตัวอย่างประโยคหลังเลือก
- การประเมินตนเองปรับสถานะต้องทบทวน และสรุปจำนวนที่จำได้หรือยังจำไม่ได้เมื่อจบรอบ

## US-09 Challenge เลือกคำตอบ

- เลือกให้คำถามเป็นอังกฤษ (ตัวเลือกเป็นความหมายไทย) หรือไทย (ตัวเลือกเป็นคำอังกฤษ) ได้
- คำถามมีตัวเลือกไม่เกิน 4 ข้อที่มาจากคำในคลัง ตัวเลือกผิดเลือกคำที่มีชนิดของคำหรืออักษรแรกเดียวกับคำตอบก่อน และไม่ใช้คำที่มีความหมายซ้ำกับคำตอบ จึงมีคำตอบถูกเพียงข้อเดียว; ถ้าคลังมีคำไม่พอ แสดงตัวเลือกเท่าที่มีพร้อมข้อความแจ้ง
- เลือกด้วยการคลิกหรือกดปุ่มตัวเลข 1–4; ตอบถูกแสดงสีเขียวแล้วไปคำถัดไปเอง และยกเลิกสถานะต้องทบทวน
- ตอบผิดแสดงข้อที่เลือกเป็นสีแดง ข้อที่ถูกเป็นสีเขียว และเก็บคำไว้ทบทวน แล้วรอให้กด Enter หรือ `คำถัดไป`

## US-10 จำการตั้งค่า

- ภาษาของด้านหน้าหรือคำถาม (ENG/THAI) รูปแบบ Challenge เสียงตอบรับ การสุ่มคำ และจำนวนคำต่อรอบ ถูกเก็บในเบราว์เซอร์และยังเหมือนเดิมหลังโหลดหน้าใหม่
- ค่าที่บันทึกไว้ผิดรูปแบบถูกแทนด้วยค่าเริ่มต้นเฉพาะค่านั้น

## US-11 ทบทวนตามช่วงเวลา

- ทุกคำตอบใน Challenge ส่งไปบันทึกพร้อมวันที่ท้องถิ่นของผู้เรียน: ตอบถูกเว้นไป 1, 3, 7, 14, 30 และ 60 วันตามจำนวนครั้งที่ถูกติดกัน (ค้างที่ 60 วัน); ตอบผิดเริ่มนับใหม่และถึงกำหนดในวันนั้น
- ตอบถูกยกเลิกดาวต้องทบทวน ตอบผิดติดดาว ส่วนดาวที่กดเองในคลังหรือหน้าอ่านบัตรไม่เปลี่ยนตารางทบทวน
- คำที่ยังไม่เคยตอบไม่ถึงกำหนด; คำที่วันกำหนดตรงหรือเลยวันนี้ถึงกำหนด
- แถบซ้ายและหน้าสถิติแสดงจำนวนคำที่ถึงกำหนดวันนี้ และปุ่ม `ทบทวนเลย` เปิด Challenge ที่กรองเฉพาะคำถึงกำหนดทุกหมวด

## US-12 สถิติการฝึก

- หน้าสถิติแสดงจำนวนวันที่ฝึกต่อเนื่อง (นับถึงวันนี้ หรือถึงเมื่อวานถ้าวันนี้ยังไม่ได้ฝึก) จำนวนคำที่ตอบวันนี้ เปอร์เซ็นต์ตอบถูก และจำนวนคำถึงกำหนด
- กราฟแท่งแสดงจำนวนคำตอบ 14 วันล่าสุด แตะหรือชี้แท่งเพื่อดูวันที่ จำนวน และเปอร์เซ็นต์ถูก และมีตารางสำหรับโปรแกรมอ่านหน้าจอ
- ระดับความจำแบ่งเป็น ยังไม่เคยฝึก, กำลังจำ (ถูกติดกันไม่เกิน 1), เริ่มคุ้น (2–3) และจำได้แม่น (4 ขึ้นไป) พร้อมจำนวนคำ
- รายการคำที่ตอบผิดบ่อยแสดงสูงสุด 10 คำพร้อมจำนวนครั้งที่ผิดและถูก
- ประวัติคำตอบยังอยู่หลังลบบัตร จึงนับวันที่ฝึกต่อเนื่องได้ถูกต้อง

## US-13 รหัสผ่าน

- เมื่อ backend ตั้ง `APP_PASSWORD` เว็บแสดงหน้าเข้าสู่ระบบก่อนเห็นคำศัพท์ และ API ทุกเส้นยกเว้น health, session และ login ตอบ `401` ถ้าไม่มี token ที่ถูกต้อง
- ใส่รหัสว่างหรือผิดแสดงข้อความภาษาไทย; ใส่ผิด 5 ครั้งจากที่อยู่เดียวกันหรือรวม 50 ครั้งใน 15 นาทีถูกปฏิเสธชั่วคราว โดยนับจากฐานข้อมูลจึงมีผลกับทุก instance ของ serverless
- เข้าสู่ระบบแล้วใช้ได้ 30 วันบนอุปกรณ์นั้น; เปลี่ยนรหัสผ่านทำให้ทุกอุปกรณ์ต้องเข้าสู่ระบบใหม่
- เมื่อ API ตอบ `401` ระหว่างใช้งาน หรือกด `ออกจากระบบ` เว็บลบ token และคำศัพท์ที่เก็บในเบราว์เซอร์ แล้วกลับไปหน้าเข้าสู่ระบบ
- ถ้าไม่ตั้ง `APP_PASSWORD` เว็บและ API เปิดใช้ได้โดยไม่ต้องเข้าสู่ระบบ

## US-14 ฝึกประจำวัน

- `ฝึกวันนี้` รวมคำที่ถึงกำหนดทบทวน (สุ่มลำดับ) ต่อด้วยคำใหม่ที่ยังไม่เคยตอบ ไม่เกินจำนวนคำใหม่ต่อวันลบด้วยจำนวนคำที่เริ่มฝึกไปแล้ววันนี้
- กล่องฝึกวันนี้อยู่ในแถบซ้ายบนจอกว้างและบนสุดของคลังบนมือถือ แสดงเป้าหมายต่อวันพร้อมแถบความคืบหน้า จำนวนคำถึงกำหนด คำใหม่ และปุ่มเริ่ม
- เป้าหมายนับจากจำนวนคำตอบใน Challenge วันนี้ ตั้งเป็น 10, 20, 30, 50 หรือไม่ตั้งได้

## US-15 ตั้งค่าอุปกรณ์

- ปุ่ม `ตั้งค่า` (แถบซ้ายหรือไอคอนเฟืองบนมือถือ) เปิดหน้าตั้งค่าเป้าหมายต่อวัน คำใหม่ต่อวัน (0, 5, 10, 20) ความเร็วเสียงอ่าน (ช้า, ปกติ, เร็ว) สำเนียง (อเมริกัน, อังกฤษ) พร้อมปุ่มทดลองฟัง และธีม (ตามระบบ, สว่าง, มืด)
- ธีมมืดใช้ทั้งเว็บรวมหน้าเข้าสู่ระบบ ถูกใส่ก่อนหน้าเว็บแสดงครั้งแรกจึงไม่กะพริบเป็นสีขาว และ `ตามระบบ` เปลี่ยนตามระบบปฏิบัติการทันที
- ค่าตั้งทั้งหมดเก็บในเบราว์เซอร์ของอุปกรณ์นั้น

## US-07 ย้ายข้อมูลเดิม

- เมื่อ backend เริ่มทำงาน migration รวมบัตรที่มีคำสะกดเดียวกันโดยไม่สนตัวพิมพ์เป็นหนึ่งบัตร และเก็บชนิดของคำกับความหมายเดิมไว้
- หากบัตรเดิมมีคำใบ้หลายค่า ให้เก็บข้อความคำใบ้ไว้; หากบัตรใดของคำนั้นต้องทบทวน บัตรที่รวมแล้วต้องทบทวนด้วย
- การเริ่ม backend ซ้ำไม่สร้างคำที่ลบไปแล้วกลับมา และไม่สร้างบัตรซ้ำ

## US-08 โหลดคำศัพท์เมื่อเปิดเว็บ

- ถ้าเบราว์เซอร์เคยโหลดคำศัพท์สำเร็จ แสดงรายการนั้นได้ทันทีระหว่างรอ API และเปลี่ยนเป็นข้อมูลล่าสุดเมื่อ API ตอบ
- ถ้า API ล้มเหลว ข้อมูลที่เคยโหลดไว้ยังอ่านได้พร้อมข้อความผิดพลาด; ถ้าไม่มีข้อมูลที่เคยโหลด ให้แสดงสถานะกำลังโหลดจนกว่าคำขอจะจบ
