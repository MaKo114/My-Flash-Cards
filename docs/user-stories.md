# User Stories

ขอบเขต: แอปคำศัพท์ชุดเดียวสำหรับผู้ใช้คนเดียว หนึ่งคำสะกดมีหนึ่งบัตรซึ่งเก็บชนิดของคำและความหมายได้หลายรายการ โดยไม่จับคู่รายการทั้งสองตามตำแหน่ง

| ID | User story |
| --- | --- |
| US-01 | ในฐานะผู้เรียน ฉันต้องการเพิ่ม แก้ไข และลบคำศัพท์ พร้อมชนิดของคำหลายค่า ความหมายหลายค่า และคำใบ้ เพื่อเก็บคำจากหนังสือได้โดยไม่ต้องสร้างบัตรซ้ำ |
| US-02 | ในฐานะผู้เรียน ฉันต้องการนำเข้า CSV เพื่อเพิ่มหลายคำและรวมข้อมูลใหม่เข้ากับคำที่มีอยู่ โดยเห็นผลของแต่ละแถวที่นำเข้าไม่ได้ |
| US-03 | ในฐานะผู้เรียน ฉันต้องการค้นหาและกรองคำศัพท์ รวมถึงเลือกหลายคำเพื่อลบ เพื่อจัดการคลังคำศัพท์ได้สะดวก |
| US-04 | ในฐานะผู้เรียน ฉันต้องการอ่านบัตรตามหมวดอักษรหรือคำที่ต้องทบทวน สุ่มลำดับ พลิกบัตร ดูคำใบ้ สลับด้านแรก และฟังคำอ่าน เพื่อฝึกจำ |
| US-05 | ในฐานะผู้เรียน ฉันต้องการฝึกพิมพ์ตามคำหรือฟังเสียงแล้วพิมพ์ โดยเห็นสีถูกผิดทีละอักษรและพิมพ์คำสะกดหนึ่งครั้งต่อรอบ เพื่อฝึกสะกดคำ |
| US-06 | ในฐานะผู้เรียน ฉันต้องการทบทวนความหมาย ดูเฉลย และประเมินตัวเอง เพื่อเก็บหรือยกเลิกสถานะต้องทบทวน |
| US-07 | ในฐานะผู้ใช้เดิม ฉันต้องการให้ข้อมูลบัตรรูปแบบเก่าถูกรวมตามคำสะกดโดยรักษาข้อมูลเดิมไว้ เพื่อใช้งานต่อหลังอัปเดตระบบ |

เกณฑ์รับงานแต่ละเรื่องอยู่ใน [acceptance-criteria.md](acceptance-criteria.md) และสัญญา HTTP อยู่ใน [openapi.yaml](../openapi.yaml)
